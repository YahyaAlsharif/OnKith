to launch QEMU
1-download and install QEMU .exe installer
2-download the arm64 iso of debian
3-copy the "edk2-aarch64-code.fd" from "C:\Program Files\qemu\share\edk2-aarch64-code.fd" which is the uefi used to boot the system from and paste it in a special file u create and decide where to have it
4-paste the ISO too in the file along with "edk2-aarch64-code.fd"
5-open the power shell and type "cd 'your directory location' "
6-type the command & " "C:\Program Files\qemu\qemu-img.exe" create -f qcow2 debian-pi5.qcow2 'HOW MUCH STORAGE YOU WANT IN GB'G "
7-once the "debian-pi5.qcow2" file is created type in the power shell

& "C:\Program Files\qemu\qemu-system-aarch64.exe" `
   -M virt `
   -cpu cortex-a76 `
   -smp 4 `
   -m 4G `
   -bios edk2-aarch64-code.fd `
   -cdrom name-of-the-iso `
   -drive file=debian-pi5.qcow2,if=virtio `
   -device virtio-gpu-pci `
   -device qemu-xhci `
   -device usb-kbd `
   -device usb-tablet
